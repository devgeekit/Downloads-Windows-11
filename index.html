Проверка скачанного файла

Чтобы проверить целостность и подлинность скачиваемых данных, выполните следующие действия:

  1. Скачайте ISO-файл выбранного продукта и следуйте инструкции по установке.
  2. Запустите Windows PowerShell. Если вам нужна помощь в поиске расположения PowerShell для своей операционной системы, перейдите сюда.
  3. В PowerShell вычислите хэш-значение для скачиваемого ISO-файла с помощью командлета Get-FileHash. Например:
    Get-FileHash C:\Users\Имя Пользователя\Downloads\Win11_25H2_Russian_x64_v2.iso
  4. Если выходные данные SHA256 совпадают со значением (см. таблицу ниже) для продукта, который вы скачали, это подтверждает, что файл не был поврежден, подделан или изменен по сравнению с оригиналом.

Узнайте больше о командлете Get-FileHash.
